# Edoardo Basili — sito Jekyll

Sito personale mobile-first per GitHub Pages.

## Test locale consigliato
Richiede Ruby 3.3.

```bash
bundle install
bundle exec jekyll serve
```

Apri http://127.0.0.1:4000

## Deploy GitHub Pages
1. Crea un repository GitHub e carica tutti i file.
2. Vai in **Settings → Pages**.
3. In **Build and deployment**, scegli **GitHub Actions**.
4. Fai push sul branch `main`: il workflow in `.github/workflows/jekyll.yml` farà build e deploy.
